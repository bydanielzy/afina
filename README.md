# Afina

Afina es una aplicación para Windows que te ayuda a optimizar y poner a punto tu PC, con cada opción explicada y un interruptor para activarla o desactivarla.

## Qué hace

- **Examen de tu PC.** Al abrir, revisa tu equipo (procesador, memoria, disco, tarjeta gráfica, temperatura) y te da un puntaje.
- **Ruta de optimización.** Una guía paso a paso que aplica las mejoras en el orden recomendado y que puedes deshacer cuando quieras.
- **Ajustes de Windows.** Cientos de ajustes de rendimiento, privacidad, apariencia, energía, juegos y red, cada uno con su explicación.
- **Apps de inicio.** Mira y controla qué programas arrancan con Windows.
- **Herramientas del sistema.** Limpieza de archivos, liberar memoria, planes de energía, placas de red y periféricos (mouse, teclado, USB).
- **NVIDIA.** Lee y ajusta opciones de tu tarjeta gráfica.
- **Para jugar.** Modo Juego, superposiciones (mira, monitor de rendimiento, chat), Entrenar puntería, grabar clips y un escalador de imagen con generación de cuadros.
- **Todo es reversible.** Afina guarda el valor original de cada cambio para que puedas volver atrás.

## Requisitos

- Windows 10 u 11 de 64 bits.

## Instalar

1. Descarga el instalador más reciente desde **[Releases](../../releases/latest)**.
2. Ábrelo. Como no tiene firma de pago, Windows puede mostrar «Windows protegió su PC»: pulsa **Más información → Ejecutar de todas formas**.
3. Para entrar necesitas una cuenta. Las cuentas las crea el autor; pídesela.

## Actualizaciones

Desde la versión 0.3.0, Afina te avisa cuando hay una versión nueva y puede instalarla sola desde **Preferencias → Buscar actualizaciones**.
